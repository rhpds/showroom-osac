= Introduction to Red Hat cloud extensions

Welcome to Introduction to Red Hat cloud extensions!

You're a Platform Engineer at Sovereign Cloud Corp, a European government services provider. Leadership has handed you a critical mission: deploy a sovereign cloud platform on OpenShift that meets strict data sovereignty and regulatory compliance requirements. The platform must support multiple government tenants, automate workload provisioning through a service catalog, and integrate with Keycloak for identity management.

This isn't just another cloud deployment. Your government clients need to know their data never leaves their jurisdiction, and every workload must be provisioned through an auditable, compliant process. You have the tools — and this workshop shows you how to use them.

== What you'll learn

In this workshop, you will:

* Navigate and understand the Red Hat cloud extensions platform architecture and components
* Create and manage multi-tenant environments with storage
* Use the cloud extensions user interface as well as the `osac` CLI to create catalog items and deploy workloads
* Verify platform health and tenant readiness

== Who this is for

This workshop is designed for Platform Engineers and Cloud Architects who want to deploy and manage a complete Red Hat cloud extensions platform, including multi-tenant environments and automated workload provisioning.

**Experience level**: Intermediate

== Prerequisites

Before starting this workshop, you should have:

* Familiarity with OpenShift or Kubernetes concepts (pods, namespaces, operators)
* OpenShift concepts — projects, namespaces, operators, and the `oc` CLI
* Kubernetes resource types, including Custom Resource Definitions (CRDs)
* Reading and editing YAML
* Familiarity with Virtual Machines and VM management concepts
* Linux command-line usage at an intermediate level
* Basic command-line experience with `oc` or `kubectl`
* Understanding of multi-tenancy and role-based access control (RBAC)

== Workshop environment

Your environment includes a pre-deployed OpenShift cluster with Red Hat cloud extensions already installed. All platform components — the fulfillment service, Keycloak identity management, Kafka event streaming, and the Red Hat cloud extensions UI — are running and ready to use.

You will work through the modules using two tabs in your lab interface:

* *Instructions*: - on the left, for step-by-step guidance and explanations
* *Lab*: - on the right, for access to the Red Hat cloud extensions UI, OpenShift Console, and a terminal for CLI commands
** *Red Hat cloud extensions Console* - to administer Red Hat cloud extensions
** *OpenShift Console* — for visual exploration of the cluster and platform components
** *Keycloak Console* - to explore identity management and user roles
** *Terminal* — for CLI commands using the `oc` and `osac` tools

Your access details are provided in the **Credentials** page for reference. They are also provided in the instructions at the point where you need them.

== Timing and Schedule

=== Full Workshop (90 minutes)

* *Module 1*: Exploring the Red Hat cloud extensions Platform (30 minutes)
* *Module 2*: Managing Tenants (30 minutes)
* *Module 3*: Virtual Machine as a Service — VMaaS (30 minutes)

Each module builds on the previous one. No formal breaks are scheduled — pause between modules as needed.

Work at your own pace. If time is short, focus on Modules 1 and 2 for the core platform concepts. Module 3 requires Module 2 (it uses the tenant and users created there).
